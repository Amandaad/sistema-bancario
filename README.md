# Sistema Bancário (Node + Angular)

Aplicação bancária com backend em **Node.js (Express)** e frontend em **Angular (standalone via browser)**.

## Funcionalidades

- Login e Sign Up
- Criação e listagem de contas
- Extrato por conta
- Depósito e saque
- Transferência entre contas
- Formulários no frontend Angular
- Consumo de APIs externas (ViaCEP e cotação USD/BRL)

## Como executar

```bash
npm install
npm start
```

Abra no navegador: `http://localhost:3000`
